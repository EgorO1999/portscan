# TCP Port Scanner

Библиотека на Go для параллельного TCP-сканирования портов.

Позволяет проверять доступность портов на IPv4, IPv6 и доменных именах, ограничивать количество одновременных подключений и управлять сканированием через `context.Context`.

## Основные возможности

- TCP-сканирование портов методом TCP Connect.
- Параллельная обработка с использованием горутин.
- Поддержка IPv4, IPv6 и DNS.
- Настраиваемое количество одновременных подключений.
- Настраиваемый таймаут подключения.
- Отмена сканирования через контекст.
- Передача результатов через канал.
- Обработка сетевых ошибок и удаление дубликатов.

## API

### New(opts ...Option) (*Scanner, error)
Создаёт новый экземпляр сканера с указанными настройками.

### WithConcurrency(n int) Option
Устанавливает максимальное количество одновременных TCP-подключений.

### WithConnectTimeout(timeout time.Duration) Option
Устанавливает максимальное время ожидания TCP-подключения.

### Scan(ctx context.Context, hosts []string, ports []uint16) (<-chan Result, error)
Запускает сканирование указанных хостов и портов. Возвращает канал результатов и ошибку, если входные данные некорректны или DNS-разрешение не удалось.

### Ports(values ...int) ([]uint16, error)
Формирует список портов, проверяет допустимость значений и удаляет дубликаты.

### Range(start, end int) ([]uint16, error)
Создаёт диапазон портов с включёнными границами.

### Union(groups ...[]uint16) []uint16
Объединяет несколько списков портов, исключая повторения.

## Результат сканирования

Структура `Result` содержит:

- `Host` — исходное имя хоста.
- `IP` — IP-адрес проверяемого узла.
- `Port` — номер TCP-порта.
- `State` — состояние порта.
- `Duration` — время выполнения проверки.
- `Err` — ошибка подключения.

**Возможные состояния:** `open`, `closed`, `timeout`, `unreachable`, `canceled`, `error`.

## Тестирование

Проект содержит модульные тесты для проверки TCP-подключений, обработки ошибок, ограничения параллелизма, отмены контекста и DNS-разрешения.

Поддерживается проверка на гонки данных через `go test -race ./...`.
